# PiloMill stand: Fusion only

Use Autodesk Fusion for all modeling and revisions in this folder. Do not modify
or regenerate this project in FreeCAD. The user's open saved PiloMill-L document
is authoritative; preserve unrelated changes and inspect before editing.

Save the active Fusion document and refresh `fusion/PiloMill-L.f3d`, STEP and
validation after scoped edits. Inspect native feature health, dimensions and
solid count. Do not claim imported bodies have a complete parametric history.
Use the configured local Fusion API/MCP connection when available.

Keep old revisions and generation tools outside this repository in recoverable
backups. Preserve physical-fit limitations and test coupons. CAD work never
authorizes printer or CNC operation. See `docs/development/mount-arm.md`.
